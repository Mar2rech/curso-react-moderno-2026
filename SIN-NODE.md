# Practicar el curso sin instalar Node.js

Si estás en un equipo donde no puedes instalar Node.js, puedes seguir el curso perfectamente usando entornos online que ejecutan Vite + React en el navegador.

## Opción recomendada: StackBlitz

StackBlitz corre proyectos Vite + React **completamente en el navegador** (usando WebContainers). Es la experiencia más parecida a tener Node local.

### Empezar un proyecto nuevo (recomendado para practicar)

1. Abre: **https://vite.new/react**
2. Espera a que se cargue (instala dependencias automáticamente).
3. Ya tienes un proyecto React + Vite corriendo. Puedes editar `src/App.jsx` y ver los cambios al instante.

### Abrir los archivos de este repositorio

Puedes abrir el repo del curso directamente en StackBlitz:

**https://stackblitz.com/github/Mar2rech/curso-react-moderno-2026**

(Opcional: añade `?startScript=dev` al final para que intente arrancar el servidor).

> Nota: Como el proyecto principal está en la carpeta `01-fundamentos`, puede que necesites entrar en esa carpeta o copiar los archivos relevantes al editor.

### Otras opciones

| Plataforma | Enlace rápido | Notas |

| **StackBlitz** | [vite.new/react](https://vite.new/react) | La mejor opción. Vite real en el navegador. |

## Cómo seguir el curso online

1. Abre StackBlitz con un proyecto React + Vite.
2. Ve copiando los conceptos y código de los módulos del repositorio (o de las explicaciones que te dé).
3. Practica modificando el código y viendo el resultado al momento.
4. Cuando puedas instalar Node en otro equipo, podrás clonar el repo y trabajar localmente.

## Ventajas de StackBlitz

- No necesitas instalar nada.
- Hot Module Replacement real.
- Terminal integrada.
- Puedes instalar paquetes npm normalmente.
- Puedes descargar el proyecto como ZIP cuando quieras.

¡Empieza por [https://vite.new/react](https://vite.new/react) y avísame cuando lo tengas abierto!
