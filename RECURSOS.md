# Recursos y lugares de consulta

Lista viva de referencias recomendadas para el curso. Se irá actualizando.

## Documentación oficial (prioritaria)

- [React Docs](https://react.dev) — La fuente principal. Especialmente las secciones de Hooks, Actions y React 19.
- [Vite](https://vite.dev) — Documentación del bundler que usamos.
- [React Router](https://reactrouter.com) — Cuando lleguemos al módulo de routing.

## Comunidad y discusiones actuales (2026)

- [r/reactjs](https://www.reddit.com/r/reactjs) — Foro principal de discusión.
- [This Week In React](https://thisweekinreact.com) — Newsletter semanal de Sébastien Lorber.
- Búsquedas en X/Twitter: "React 19", "React Compiler", "Server Components", "TanStack".

## Librerías y herramientas mencionadas en el curso

- [TanStack Query](https://tanstack.com/query) — Server state.
- [Zustand](https://zustand-demo.pmnd.rs) — Client state ligero.
- [TanStack Start](https://tanstack.com/start) — Alternativa a Next.js.
- [React Compiler](https://react.dev/learn/react-compiler) — Optimización automática.

## Herramientas de desarrollo

- React DevTools (extensión de navegador)
- Vite + Oxc / React Compiler (cuando profundicemos)

## Notas

- Siempre prioriza la documentación oficial sobre tutoriales antiguos.
- Create React App está obsoleto: usamos Vite.
- Class components no se enseñan como primera opción.
