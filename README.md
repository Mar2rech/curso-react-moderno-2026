# Curso React Moderno 2026

Repositorio oficial del curso **React Moderno 2026: De los fundamentos a una aplicación real**.

Todo el código, ejercicios, proyectos y materiales del curso se irán subiendo aquí de forma progresiva.

## Filosofía del curso

El curso está diseñado para ser **regulable en ritmo**:

- **Camino principal** → fundamentos sólidos y prácticos (avance constante).
- **Módulos de profundización** → temas modernos que se discuten actualmente en la comunidad (puedes ir más despacio o saltarlos según interés).

## Camino principal

1. Setup moderno con Vite + React 19.3
2. Componentes funcionales, JSX, props y composición
3. Estado local (`useState`) y eventos
4. Listas, keys y renderizado condicional
5. Efectos (`useEffect`) bien usados
6. Formularios con Actions de React 19
7. Routing (React Router)
8. Estado compartido básico + separación server/client state
9. Proyecto final

## Módulos de profundización (opcionales)

- React 19.3 features (View Transitions, Fragment Refs, `use(browser())`, Context en Server Components)
- React Compiler
- Server Components y boundaries
- TanStack Query + Zustand
- TanStack Start / React Router Framework Mode
- Performance real (waterfalls, virtualización, concurrency)
- TypeScript + Zod
- Optimistic updates
- Testing (Vitest + Playwright)
- Accesibilidad y DX
- Arquitectura de carpetas

## Cómo seguir el curso

1. Clona este repositorio.
2. Ve avanzando por los módulos en orden.
3. Haz commits de tu progreso en ramas propias si quieres.
4. Los materiales oficiales se irán añadiendo en `main`.
